# BancoCombobox logo presentation

The field now displays an available compact selected logo; options pair the compact logo and bank name with the available horizontal mark. The horizontal mark hides on narrow viewports; selection, accessible option names and callbacks remain unchanged. No additional logo is rendered for custom/unknown names or missing source assets.

Set `showSelectedLogo={false}` for the prior text-only field and `showHorizontalLogo={false}` for compact-only options. Existing `logoProps` customization remains supported. Component colors still come from the consumer theme, not this gallery identity.
